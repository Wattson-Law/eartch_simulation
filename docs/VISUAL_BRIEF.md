# 2D 视觉与 Gemini 素材协作约定

状态：2026-09-19 第一版统一视觉包已接入；本文同时作为后续替换素材时的约束与验收底稿，最终项目边界以 [`PROJECT.md`](../PROJECT.md) 为准。

## 已确认的体验

启动时看到一颗具有体积感、地表持续自转的小地球，点击后进入黄石公园 2D 风景。动物与环境是可独立控制的动画元素，种群曲线、事件日志和巡护员解释仍由现有生态模拟驱动。

技术上沿用 React + TypeScript + Vite、Canvas 2D、SVG 与 CSS。伪 3D 地球通过绘本地图的连续球面投影和固定光照实现；黄石通过图层、遮挡和可选的轻量视差表现纵深。新增渲染引擎、3D 模型、3D 地形和运行时 Gemini 接口均不在本轮范围内。

## 画风确认顺序

1. **一张主场景参考图**：本轮已用主场景样张锁定整体画风、视角、色板、光照与画面密度，并留出动物活动区域。
2. **一组动物样张**：让狼、鹿、兔保持一致的线条、材质、比例与光照。模型中的 `elk` 指黄石的 wapiti；现有中文「麋鹿」为原型标签，生成参考应使用 elk / wapiti，避免画成驼鹿或中国麋鹿。后续接入素材时同步核对 UI 与文档中的物种名称，本次不改模拟字段或中文指令。
3. **地球样张**：确定与场景协调的体积感、表面细节和自转节奏。
4. **动作小样**：本轮已扩展到三种动物、各四组动作和完整环境循环；后续新增动作仍按同一小样验收流程。

当前运行素材位于 `public/assets/ecosystem-v1/`，可通过 `?view=assets` 预览并逐帧检查。manifest 记录尺寸、帧率、循环和脚底锚点；来源与 AI 生成说明见 [`public/assets/CREDITS.md`](../public/assets/CREDITS.md)。

可讨论的风格包括绘本插画、像素美术和剪纸分层插画；这些只是候选。旧文档的「扁平插画已定」以及当前占位素材均不代表最终选择。

主场景沿用拉马谷生态叙事。原型中的间歇泉是黄石地貌的艺术化组合，不能把合成构图标成真实拉马谷地理复原。

## 动画讨论清单

下表是制作优先级建议，不是已完成清单。先确认最小动作组合，再确定帧数、帧率和时长。

| 对象 | 当前首版 | 后续可扩展 | 驱动方式 |
|---|---|---|---|
| 地球 | 绘本世界地图的连续球面投影 | 更多地表细节或季节地图 | 独立视觉时钟；点击进入 |
| 宇宙背景 | 深空底色、星云/银河雾带、三层星群、大气辉光 | 流星或更细微的星云变化 | 与地球共用暂停时钟；按经度产生轻量视差 |
| 狼 | 待机、行走、奔跑、嚎叫 | 警觉、捕食动作 | 状态选择动作，捕食读已发生事件 |
| 鹿 | 待机、进食、行走、奔跑 | 抬头警觉、退避 | 生态状态提示与事件反馈 |
| 兔 | 待机、跳跃、奔跑、警觉 | 进食循环 | 生态状态提示与事件反馈 |
| 风景 | 蒸汽、水面、草木轻摆、云漂移 | 更细近景视差 | 环境循环 |
| 天气与季节 | 雨、雪、季节色调、火灾覆盖 | 火烟与灾后恢复过渡 | 读取降雨、季节、火灾状态 |
| 捕食叙事 | 主场景内潜行、追逐、逃脱、扑击和休息 | 更丰富的个体姿态 | 追逐可失败；捕获成功需有模拟捕食事件 |

场景画出的动物是种群代表，不要求一只精灵对应一只真实个体。待机、行走等视觉行为不增加新的生态方程。动物连续移动，步态按实际距离推进，位置不会因窗口缩放而重新生成。暂停时停止行为与环境时钟，系统的减少动态效果偏好也会停止画面运动。

## 素材拆分与交付

### 场景

- 背景按天空、远山、中景地形、林地/草地、河流、前景植被拆开；参考图用于锁定风格，运行素材按图层交付。
- 可活动动物、云、蒸汽和天气不要绘死在静态背景里；水面若需流动，应拆出可独立动画化的区域。
- 图层使用同一 2048×1152 画布、视角和地平线，可叠加部分使用真实透明通道；运行时以 16:9 容器等比合成。
- 接入网页的图像不烘焙按钮、文字、聊天框或图表，这些由 React / SVG 绘制。

### 地球与动物

- 当前地球运行素材优先交付 2:1 经纬地图：海岸线跨左右边缘时需连续，地图可由 Canvas 2D 正射投影到球面。若另交固定机位的自转帧，球心、球体大小、转轴和光照也必须保持一致，末帧平滑接回首帧。两种方式都要求地表绕球体运动，不能让整张圆图在屏幕内打转。
- 动物按「物种 + 动作」分别交付透明 PNG 序列帧或单行 Sprite Sheet。当前 `drawSheetFrame` 按横向等宽格读取；其他排列接入前需整理为兼容格式。
- 每组动作记录单帧宽高、总帧数、顺序、帧率、是否循环、朝向和脚底锚点；单行图宽应等于单帧宽乘以帧数。
- 同一动物各帧保持造型、相机、光向与落脚基线一致；帧内留足动作边距，防止耳朵、尾巴或四肢被裁切。
- 帧数、分辨率和帧率由小样效果决定，不以模型一次生成成功为前提。序列帧需检查抖动、重复/漏帧、肢体变化和首尾接缝。

### 接入和来源

- 运行时资产放入 `public/assets/`，通过 `src/assetsPaths.ts` 的路径函数引用，保持 `/eartch_simulation/` 子路径兼容。
- Gemini 的模型、生成日期、提示词、参考来源和后期处理方式应单独记录；现有 `public/assets/CREDITS.md` 的 CC0 声明仅适用于原有第三方素材，不能自动套用到新生成资产。
- 若生成结果没有准确透明通道或精灵格，应先做去背、切帧、尺寸归一和拼接，再进入应用。整段视频可作动作参考；运行时素材优先采用可控的帧图和图层。

## Gemini 提示词的后续结构

画风样张通过后，将提示词拆成以下任务，而不是一次请求模型生成整个应用：

1. **风格与构图探索**：黄石主场景参考，确定 `[风格]`、`[视角]`、`[色板]`、`[光照]` 与 `[画布]`。
2. **背景图层制作**：沿用已确认参考，只生成指定图层；标明哪些区域透明、哪些区域供动物活动。
3. **动物设定与动作**：指定单物种、单动作、固定朝向/基线/光照，以及 `[帧数]`、`[单帧尺寸]`、`[循环要求]`。
4. **地球自转**：指定固定相机、球心和转轴，地表沿经度连续移动，禁止镜头绕行或整张贴图平面旋转。
5. **环境循环**：独立生成蒸汽、水面或草木等元素，指定背景透明要求与循环接缝要求。

每条后续提示词都应附带同一套已确认的风格约束和对应参考图；若替换现有素材，需保持 manifest 中的画布、帧尺寸、透明通道、锚点和循环约束。

## 接入验收

- 图层可组合，动物可单独移动和换动作，文字与界面清晰可用。
- 伪 3D 地球自转可辨识；动物脚底不跳动，循环首尾没有明显接缝。
- 窗口缩放后素材、遮挡关系和交互区域仍对应。
- 捕食与天气只响应模拟状态；同一生态输入在不同动画帧率下得到相同数值结果。
- 每批素材验收后运行 `npm run lint`、`npm run build`，并在浏览器中检查实际画面与交互。

## 2026-09-20 动态细化

- 9 组移动和特殊动作使用 32 帧透明横向图集，原始 8 帧每隔 4 帧保留，补间不改变周期。待机保持原图并叠加连续呼吸。
- 行走 / 跑跳按移动距离推进，动作切换在 0.22 秒内衔接；转向有短暂侧身过渡。
- 草丛位置由行为和渲染共享，动物实际沿路径穿过遮蔽物。使用草叶 alpha 局部遮挡，避免整张动物突然切到植物前后。
- 天空移除烘焙云，再叠加太阳与 3 层独立云；游鱼采用连续曲线形变，位于水面波纹和岸边植物之下。
- 云、草叶、游鱼、太阳和动物使用同一暂停时钟。鱼为环境视觉元素，现有五类种群模型不变。
- 后续替换素材仍需检查中间帧的肢体完整性、步态周期和遮挡，不以增加帧数替代视觉验收。

## 可旋转的绘本地球

- 入口沿用 `earth/map.png` 的海蓝、草绿、奶油色陆地和深色海岸线，用 Canvas 2D 连续投影形成自转；不按 8 fps 图集切帧，不新增 3D 引擎或运行时依赖。
- 地球外围使用程序绘制的宇宙背景：深蓝径向底色、青蓝和紫色星云、斜向银河雾带、远中近三层共 132 颗星，以及球体外的大气辉光和淡轨道线。星点分布固定，运行时只做轻微闪烁、漂移和随经度变化的视差，保持绘本质感并避免画面噪声。
- 鼠标 / 触屏拖动与松手惯性共用连续经度；暂停固定地球、星群和标记光圈，手动旋转仍可用。定位黄石采用最短角度平滑回转。
- 黄石标记按约 110.59°W、44.6°N 与地图共享正射投影，背面不可见、不可点。只有标记或明确的进入操作会切到生态场景，拖动不会误触。
- 方向键、空格、Home、Enter 提供键盘等效操作；减少动态偏好默认静止。地图缺失时保留同色板的程序绘制地图及全部旋转操作。
